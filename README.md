# Registration Form

A simple beginner-level registration form made with HTML, CSS, and JavaScript.

## Features
- Name, Email, Password, and Bio fields
- Real-time validation
- Error messages for empty or invalid inputs
- Character counter for Bio (max 200 characters)
- Submit button stays disabled until all fields are valid

## How to use
1. Open `index.html` in your browser
2. Fill in the form
3. Watch the validation messages and character counter update as you type
